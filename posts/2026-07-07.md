Today I set up a "Today I..." journal on my portfolio. I learned how to wire a simple Markdown build step so I can add daily entries without editing HTML by hand.

I also learned about The Jevons Paradox, which is not actually a paradox, but a counterintuitive phenomenon that occurs when a product becomes cheaper and more widely available. Instead of being used the same amount, but costing less, people find new ways to use this product. Hank Greene used the Gutenberg press as an example. When Gutenberg made the printing press peope of the time probably thought that literacy would spread and books would become more widespread. However, not a single one of them probably imagined the numerous use-cases that humanity came up with -- magazines, newspapers, homework packets... 

But the importance of this phenomenon is how it may apply to software. With AI coding, code is immensely more efficient and cheap to produce. And this excited me, not only because this means that SWE is not dead, but also because of the opportunities that this will create and the futuristic insight I feel like I've gained. Just pondering all of the ways we might find to use software in our lives has motivated me to start this blog.
